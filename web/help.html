使用教程

XMUHub 是厦大同学自己维护的资料库：往年试卷、笔记、课件、题库按课程整理好，免费看、免费下。花两分钟看完下面几步就会用了。

1 · 找资料

  1. 直接搜：首页或顶部搜索框输入课程名、老师、年份都可以，也支持拼音首字母和俗称，比如 wjf → 微积分，dxwl → 大学物理，思修、毛概、马原。
  2. 搜索结果上面是课程与分类，下面是资料。点课程进入课程页能看到这门课的全部资料。
  3. 按分类浏览：点顶部「分类」，和选课系统一样按「校选课 / 公共课 / 专业课 / 体育课 → 开课学院 → 课程」逐级展开（另有教材与参考书、工具模板两个栏目）；上方的筛选框可以快速定位。
  4. 课程页里可以按 01 真题与答案 / 02 提纲笔记 / 03 题库 / 04 课件 和年份筛选，右上角还能「在这里搜索」只搜这门课。

文件名都是统一格式：课程_时间_类型(卷别、含答案)，例如 微积分I-1_2023-2024秋_期中试卷(含答案)；标题下面灰色的小字是这份资料的具体内容说明。

2 · 预览与下载

  • 不用点进去也能看：列表里每份资料左边是第一页的缩略图，右边有「预览」按钮，点一下直接弹出内容；用键盘 ← / → 或「上一份 / 下一份」可以连续翻看同一列表里的资料，挑起来很快。
  • PDF、Word、PPT、Excel、图片、文本代码、电子书都能在线预览，压缩包可以直接看里面的文件；手机上也能看。预览不计下载次数。
  • 点「下载」即可。文件经国内加速镜像下载，不需要梯子；某条线路慢会自动换一条。
  • 特别大的文件会分成几卷，下载页会自动合并；合并失败时会列出每一卷的链接。
  • 在微信 / QQ 里打开下载不了的话，点右上角「在浏览器中打开」。

3 · 上传资料

  1. 注册 / 登录：任何邮箱都能注册，收验证码即可；用厦大邮箱会显示「厦大认证」。昵称一个字也行。
  2. 选分类：点「上传」，搜课程名（支持拼音首字母），或「在分类树里选」——点学院名字就能展开到具体课程。找不到课程就点搜索框旁边的「＋ 新增课程」，选好开课学院 / 分组、填上课程名即可。
  3. 加文件：拖进来或点选，可以一次选多个。支持任意格式：PDF、Word、PPT、Excel、图片、压缩包都行。
  4. 核对自动识别：系统会从原文件名里识别类型、学年、学期、A/B 卷、是否含答案，并生成规范文件名（「→」后面那行）。不对的改一下下拉框就行；多个文件可以用「批量设置」。
  5. 小标题和备注（选填）：小标题写这份资料具体是什么（如「王老师班期中复习题」）；备注写需要提醒大家的（如「只有选择题答案」）。
  6. 点「上传并提交」。新用户的上传要等审核员通过才公开（一般很快）；审核员可以把常传资料的同学升为「可信贡献者」，之后上传直接公开。

上传到一半刷新或关掉了也没关系：回到上传页重新选同一批文件，填过的信息会恢复，已经传完的部分不用重传。

请不要上传含他人隐私、写明「勿外传」或来源不明的加密题库，详见使用须知。

4 · 评分、评论与反馈

  • 资料页底部可以给资料打 1–5 星、写评论（比如「答案有两处错」「和今年考的很像」），帮后来的同学挑资料。
  • 发现资料侵权、有隐私或分类错了：资料页点「投诉 / 申请下架」，48 小时内处理。
  • 网站本身的问题和建议：页面底部「意见反馈」，或加 QQ 群 1106047582。

5 · 审核员指南

审核员和管理员在顶部会看到「审核」。

  • 看板：每天提交量、审核量和总文件量。
  • 待审资料：每条可以「预览」确认内容；「类型」下拉可以直接改类型和标签（例如改成 T8 电子书 → 教材）；写备注后「通过」或「驳回」。勾选多条可以批量通过 / 驳回 / 批量移动分类。
  • 待核实：导入时不确定分类的资料，确认后通过，或改分类、设为「仅内部」。
  • 投诉：先「下架」再「标记已处理」；勾「显示已处理」可以看历史。
  • 反馈、审核记录（谁在什么时候处理了什么）、待确认分类（同学新建的课程，重复的合并掉）。
  • 课程页里审核员可以勾选资料「移动选中到其他分类」，也可以改分类名称、别名（用于搜索的俗称）。
  • 已发布的资料：打开资料页，右侧有「下架」「设为仅内部」「编辑信息」（可改小标题、类型、所属分类）。下架可随时「恢复发布」。

6 · 资料群合作

如果你们的班级群、学院资料群、社团或学生组织已经整理了一批资料，欢迎合作：

  • 我们可以帮忙批量导入（网盘打包、压缩包或 GitHub 仓库都行），自动按课程归类命名，并在资料上保留来源说明。
  • 群里的同学以后可以直接在这里搜，不用在群文件里翻；新资料也可以直接传到这里，全校都能用。
  • 群管理员可以申请成为审核员，一起维护对应学院 / 课程的资料。

联系方式：QQ 群 1106047582，或在意见反馈里留言并写上联系方式。

7 · 进阶：AI 助手 / API

在「我的」页面可以创建个人令牌，给 Claude、Cursor 等支持 MCP 的 AI 助手接入本站：让它帮你搜资料、找下载链接。地址 https://xmu.vintces.icu/mcp，具体配置方法见「我的」页面的「如何连接」。

8 · 开源与参与开发

XMUHub 的全部代码都公开在 GitHub：github.com/vintcessun/XMUHub（AGPL-3.0 许可）。后端是 Rust，前端是不需要编译的普通网页，改起来很容易。

  • 觉得好用，给项目点个 ⭐ Star，让更多同学看到。
  • 发现 bug、想要新功能：在 GitHub 提 Issue，或者用右下角「反馈」。
  • 想一起开发：Fork 之后提 Pull Request；README 里有本地运行的方法。
