个人令牌 · MCP / API

给 AI 助手（Claude、Cursor 等支持 MCP 的客户端）或自己的脚本使用。令牌以你的身份和权限访问本站，只在创建时显示一次，请像密码一样保管；不用了随时删除。

如何连接

MCP 地址：https://xmu.vintces.icu/mcp（Streamable HTTP）。请求头 Authorization: Bearer 你的令牌。不带令牌也能搜索和下载公开资料。

Claude Code：

claude mcp add --transport http ludao-shuge https://xmu.vintces.icu/mcp --header "Authorization: Bearer xmh_你的令牌"

其他客户端（mcp.json / claude_desktop_config.json 等）：

{
  "mcpServers": {
    "ludao-shuge": {
      "type": "http",
      "url": "https://xmu.vintces.icu/mcp",
      "headers": { "Authorization": "Bearer xmh_你的令牌" }
    }
  }
}

提供的工具：search（搜索）、get_tree / get_category（浏览分类）、get_resource、get_download_links（下载地址）、list_recent / list_popular、get_comments、post_comment、rate_resource、submit_feedback、whoami；审核员另有 review_queue、review_resource。

REST API：同一个令牌也可以调用网站的 /api/… 接口，例如 curl -H "Authorization: Bearer xmh_…" "https://xmu.vintces.icu/api/search?q=微积分"。
